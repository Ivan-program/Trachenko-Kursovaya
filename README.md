# Чат-бот для поддержки пользователей научного портала

Курсовая работа по теме:

> **«Создание чат-бота для поддержки пользователей научного портала с использованием NLP и Dialogflow»**

Проект представляет собой прототип интеллектуального чат-бота, предназначенного для автоматизации поддержки пользователей научного портала. Чат-бот использует возможности **Google Dialogflow CX** для распознавания намерений пользователя, извлечения сущностей и управления диалогом, а также взаимодействует с backend-приложением через webhook для получения динамических данных.

## Цель проекта

Разработать и протестировать чат-бота для поддержки пользователей научного портала с применением технологий обработки естественного языка (**NLP**) и платформы **Google Dialogflow CX**.

Чат-бот должен помогать пользователям:

- находить научные публикации;
- получать информацию о конференциях;
- получать сведения о грантах;
- проверять статус заявок;
- находить справочную информацию по работе с научным порталом;
- получать ответы на типовые вопросы;
- обрабатывать неточные и неизвестные запросы через fallback-сценарии.

## Основные задачи

В рамках проекта планируется:

1. Проанализировать основные типы пользовательских запросов научного портала.
2. Спроектировать архитектуру чат-бота и пользовательские сценарии.
3. Создать агента в Google Dialogflow CX.
4. Настроить intents, entities, training phrases и диалоговые сценарии.
5. Разработать backend на Node.js, TypeScript и Express.
6. Реализовать webhook для обмена данными между Dialogflow CX и backend.
7. Создать тестовую базу данных научного портала.
8. Разработать демонстрационный веб-интерфейс на React.
9. Интегрировать чат-бота с веб-интерфейсом.
10. Провести тестирование качества распознавания пользовательских запросов.
11. Настроить Docker и Docker Compose.
12. Настроить CI/CD-пайплайн с использованием GitHub Actions.

## Принцип работы

Пользователь вводит сообщение в чат на странице научного портала.

Например:

```text
Найди публикации по машинному обучению
```

Dialogflow CX определяет намерение пользователя:

```text
Intent: search_publication
```

и извлекает сущность:

```text
science_topic = "машинное обучение"
```

После этого Dialogflow CX вызывает webhook backend-приложения.

Backend получает параметры запроса, обращается к SQLite и возвращает подходящие данные.

Пример ответа:

```text
Найдены публикации по теме «Машинное обучение»:

1. Методы машинного обучения в анализе научных данных
2. Применение нейронных сетей для классификации текстов
3. Анализ больших данных с использованием ML
```

## Планируемые пользовательские сценарии

Чат-бот будет поддерживать несколько основных групп запросов.

### Поиск публикаций

Примеры:

```text
Найди статьи по физике
Покажи публикации по биологии
Есть работы по машинному обучению?
Найди публикацию по DOI
```

### Поиск конференций

Примеры:

```text
Какие есть конференции по искусственному интеллекту?
Покажи ближайшие научные конференции
Какие конференции проходят в этом году?
```

### Информация о грантах

Примеры:

```text
Какие сейчас доступны гранты?
Найди гранты по информационным технологиям
Когда заканчивается прием заявок?
```

### Работа с заявками

Примеры:

```text
Какой статус моей заявки?
Проверь заявку 105
Что означает статус «На рассмотрении»?
```

### Поддержка пользователей

Примеры:

```text
Как опубликовать статью?
Как зарегистрироваться на портале?
Не могу войти в личный кабинет
Как изменить пароль?
```

## Webhook

Dialogflow CX взаимодействует с backend через HTTPS webhook.

Локальный адрес:

```text
http://localhost:3000/webhook/dialogflow
```

используется для разработки и тестов backend.

Для подключения webhook непосредственно к облачному Dialogflow CX backend должен иметь публичный HTTPS-адрес.

В финальной версии проекта планируется размещение backend в **Google Cloud Run**:

```text
Dialogflow CX
      │
      ▼
https://<cloud-run-service>/webhook/dialogflow
      │
      ▼
Node.js / Express
      │
      ▼
SQLite
```

## Тестирование

Тестирование проекта включает несколько уровней.

### Backend

Будут проверяться:

- REST API;
- обработчики webhook;
- корректность параметров;
- работа сервисов;
- обработка ошибок;
- взаимодействие с SQLite.

Используемые инструменты:

```text
Vitest
Supertest
```

Запуск тестов:

```bash
npm test
```

### Dialogflow CX

Для каждого intent будет подготовлен набор тестовых пользовательских фраз.

Планируется проверять:

- корректность определения intent;
- правильность извлечения entities;
- неизвестные запросы;
- неоднозначные формулировки;
- fallback-сценарии;
- работу уточняющих вопросов;
- получение динамических данных через webhook.

## Оценка качества NLP

Для тестирования будет подготовлен отдельный набор пользовательских запросов, которые не используются как training phrases.

Для каждого запроса фиксируется:

```text
Ожидаемый intent
Определенный intent
Результат распознавания
Извлеченные entities
Корректность entities
```

На основе результатов будет рассчитана доля правильно распознанных пользовательских запросов.

При необходимости дополнительно могут быть рассчитаны:

- Precision;
- Recall;
- F1-score.
