## Создание чат-бота для поддержки пользователей научного портала с использованием NLP и Dialogflow

### 1. Инициализация проекта и базовая инфраструктура

- Создание публичного репозитория проекта и базовой структуры каталогов.
- Создание `README.md` с описанием назначения чат-бота, используемого стека и инструкции по запуску.
- Выбор и настройка основных технологий проекта: Dialogflow CX, Node.js/Express для backend и простой веб-интерфейс для взаимодействия с ботом.
- Настройка базового CI/CD-пайплайна: lint → tests → build.

### 2. Анализ пользовательских запросов и проектирование чат-бота

- Определение основных категорий пользователей научного портала и типовых обращений.
- Формирование перечня запросов, которые должен обрабатывать чат-бот: поиск научных публикаций, информация о публикации материалов, конференциях и грантах, помощь при работе с порталом.
- Разработка схемы взаимодействия пользователя с чат-ботом.
- Проектирование общей архитектуры системы: пользователь → веб-интерфейс → Dialogflow → webhook → данные научного портала.

### 3. Создание и настройка агента Dialogflow

- Создание агента в Dialogflow CX.
- Разработка основных намерений пользователя (`Intents`) и обучающих фраз (`Training Phrases`).
- Создание необходимых сущностей (`Entities`) для распознавания параметров запросов, например тематики публикации, типа материала или идентификатора заявки.
- Настройка ответов чат-бота и обработки неизвестных или некорректных запросов.
- Создание простых диалоговых сценариев с уточняющими вопросами.

### 4. Разработка backend и webhook

- Создание backend-приложения на Node.js/Express.
- Реализация webhook для обмена данными между Dialogflow и backend.
- Создание тестового набора данных научного портала или простого API, содержащего сведения о публикациях, конференциях, грантах и правилах работы с порталом.
- Реализация динамических запросов чат-бота к этим данным.
- Обработка ошибок и ситуаций, когда запрашиваемая информация не найдена.

### 5. Интеграция чат-бота с веб-интерфейсом научного портала

- Создание простой демонстрационной страницы научного портала.
- Добавление на страницу пользовательского интерфейса чат-бота.
- Настройка передачи сообщений пользователя в Dialogflow и отображения ответов.
- Проверка работы статических и динамических сценариев через единый интерфейс.

### 6. Тестирование чат-бота

- Формирование тестового набора пользовательских запросов для каждого созданного намерения.
- Проверка корректности распознавания намерений и извлечения сущностей.
- Проверка работы webhook и получения динамических данных.
- Тестирование неизвестных, неточных и неоднозначных пользовательских запросов.
- Фиксация результатов тестирования и расчёт общей точности распознавания намерений.
- Исправление обнаруженных ошибок и дополнение обучающих фраз.

### 7. Контейнеризация и финализация проекта

- Создание Dockerfile для backend и веб-интерфейса проекта.
- Настройка `docker-compose.yml` для автоматического запуска локальной части системы.
- Финальная настройка CI/CD-пайплайна и проверка этапов lint → tests → build.
- Обновление `README.md`: архитектура, используемые технологии, настройка Dialogflow и инструкция по запуску.
- Подготовка демонстрационных сценариев работы чат-бота и результатов тестирования для защиты курсовой работы.
